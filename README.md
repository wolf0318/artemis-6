# 루나 알파 데이터 수사대 (아르테미스 프로젝트 6차시)

한성대학교 산학협력단 「아르테미스 프로젝트: 데이터로 달 기지 구하기!」 6차시 **데이터를 믿어도 될까?** 수업용 웹앱입니다.

- 학생용: `index.html` — 번호(1~20)와 조를 골라 들어가요. 로그인은 없어요.
  - 미션 1 속이는 차트 구별하기(교재 38쪽): 같은 숫자 다른 느낌, 속이는 차트 3형제, 온도 차트 수사, Y축 조종실
  - 미션 2 누락 데이터 탐정(교재 39쪽): 빠진 시간대·구역 찾기, 단서 카드 5·25·27·41, 수사 노트, NASA 긴급 보고서
  - 미션 3 6차시 정리(교재 40쪽): 편향된 데이터 한 줄, 차트 읽기 4단계 순서, 우주 토론 벽
- 선생님용: `teacher-q7m4.html` — 접속 현황, 미션 열기·잠그기, 전체 알림, Y축 결과, 보고서 모음, 토론 벽, 새 수업 시작

데이터는 Firebase Realtime Database(`artemis6/<room>`)에 저장됩니다. 주소 뒤에 `?room=이름`을 붙이면 반을 나눠 쓸 수 있어요(학생·선생님 주소 모두 같은 이름).
학생 이름·연락처 같은 개인정보는 받지 않습니다.
